# File XOR Processor

Программа для модификации файлов операцией XOR с 8-байтным ключом.

## Возможности

- Обработка файлов по маске (например, *.txt, testFile.bin)
- XOR операция с 8-байтным значением (hex)
- Обработка файлов большого размера (10GB+) без блокировки UI
- Пауза/возобновление обработки
- Работа по таймеру или разовый запуск
- Удаление исходных файлов (опционально)
- Перезапись или создание файлов с счетчиком

## Требования

- Qt 5.15+ или Qt 6.x
- C++17
- CMake 3.16+
- MinGW (Windows)

## Сборка

### CMake
bash
```
mkdir build
cd build
cmake ..
cmake --build .
```
